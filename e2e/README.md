# Snowpan E2E 테스트

로컬 전용 통합 테스트 — 프로덕션 DB/서버를 절대 건드리지 않는다.
격리된 Postgres(`~/.snowpan-e2e/pgdata`, 포트 5433)와 로컬 백엔드(포트 4001, DATABASE_URL 강제 주입)로 실행.

## 실행

```bash
./e2e/run.sh        # 전체 (DB 초기화 후 step1~14, 550 케이스)
./e2e/run.sh 9      # 특정 스텝만 (state 재사용, DB 초기화 안 함)
```

필요: `brew install postgresql@16`, `jq`, backend `npm install` 완료 상태.

## 스텝 구성

| 스텝 | 내용 |
|---|---|
| 1 | 회원가입 → 로그인 → 프로필 (닉네임 표시) |
| 2 | 매물 등록 / 정렬 / 브랜드·길이 필터 |
| 3 | 상세조회 → 채팅 (REST + Socket.IO 실왕복) |
| 4 | 판매완료 → 리뷰 → 평점 → 중복 거부 |
| 5 | 매물 수정 — subcategory XSS / 가격·상태 |
| 6 | 찜하기 → 찜목록 → 알림 (소켓 수신) |
| 7 | 커뮤니티 글/댓글/좋아요 + 투표 |
| 8 | 회원 탈퇴 → 익명화 (공개 표면 실명 비노출) |
| 9 | 광고 흐름 — 신청→승인→프리미엄 자동적용→클릭 추적→1년 계약 취소차단→배너 자동생성 |
| 10 | tokenVersion 세션 무효화 — 비번 변경 시 옛 토큰 즉시 거절 + 같은 초 재로그인 정상 |
| 11 | 채팅 요청 게이트 — 요청→수락 전 전송차단→수락→대화, 거절→재요청 차단, 매물 문의 승격 |
| 12 | 매장 5종(스키샵·정비샵·렌탈·레슨·숙소) 전주기 — 등록→미승인 비공개→대시보드 /my→승인→공개→소유자 수정(재심사)→타인 수정·삭제 IDOR 차단→XSS→관리자 삭제/반려, business-status |
| 13 | 매장 소식(ShopPost) 전주기(소유자·승인·일 5건·pinned 관리자 전용·미승인 매장 소유자 전용 노출·홈 피드) + 매장 리뷰(1인1리뷰·본인매장·집계) + 소유권 이전(claim) + 신고 + 저장검색 |
| 14 | 전 라우트 스모크 — 공개 GET 23종 200/JSON, 보호 30종 무토큰 401, 관리자 26종 일반유저 403, 입력 검증 400, 알림 타인 조작 차단, 프로필/판매자 공개 프로필 개인정보 마스킹, 뱃지, FCM 토큰, 추천인, 문의, 사전등록, 리조트, 해외 CRUD·딜 클릭 dedup, 여행사 전주기, 매물 끌올/본인찜, 밴→토큰 즉시 무효, 배너·광고가격 관리 |

케이스마다 개인정보(이메일·전화·실명) 공개 노출 가드가 포함된다 — 공개 응답에 `email`/`phone` 이 나오면 즉시 실패.

## 구조

- `lib.sh` — 공용 헬퍼 (휴대폰 인증 우회 가입, 로그인, psql)
- `chat.js` / `chatnotif.js` / `chatgate.js` — Socket.IO 실연결 헬퍼 (backend 의 socket.io-client 사용)
- `.state/` — 실행 간 상태 (토큰·ID·로그, gitignore)
- 시드 유지 테이블: `ski_resorts`(용평·곤지암 자동 시드)·`overseas_resorts`·`ad_slot_pricings` — 나머지는 전체 실행 시 초기화
