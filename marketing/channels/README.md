## 채널 이름·아이디 (둘 다 같은 걸로)
- 이름: **스노우판 SNOWPAN**
- 아이디: `@snowpan.kr` (인스타와 동일). 틱톡·유튜브에서 안 되면 `@snowpan_kr`
- 유튜브 핸들은 만든 뒤 14일간 못 바꾸니 처음에 확정

## 소개문
- 유튜브(설명란): 스키장 가기 전에 여는 앱, 스노우판. 전국 렌탈샵 가격 비교, 실시간 스키장 웹캠, 중고 장비 거래와 거래 약속, 정비·레슨·숙소까지. 시즌 정보와 장비 이야기를 올립니다. 앱: App Store·Google Play "스노우판" / 웹: snowpan.kr / 문의: 앱 고객센터 채팅
- 틱톡(80자 제한): 스키장 가기 전 여는 앱. 렌탈샵 가격·실시간 웹캠·중고장비. snowpan.kr
- 링크: 유튜브 '링크' 칸에 snowpan.kr, App Store, Google Play, 인스타 4개. 틱톡은 웹사이트 1개(snowpan.kr) — 비즈니스 계정으로 전환해야 링크가 열림

## 계정 설정
- 둘 다 **비즈니스/브랜드 계정**으로(틱톡: 설정 → 계정 → 비즈니스 계정 전환, 유튜브: 브랜드 계정으로 채널 생성 → 나중에 직원에게 관리 권한 줄 수 있음)
- 유튜브: 채널 키워드 "스키, 스노보드, 스키장, 렌탈샵, 중고스키, 스노우판", 국가 대한민국, 댓글 '검토 후 게시'로 시작
- 틱톡: 업로드 때 "콘텐츠 공개 설정 → 다운로드 허용 끔", 지역 대한민국
- 프로필 사진은 둘 다 black 버전 추천(흰 피드 위에서 더 눈에 띔). 인스타도 같은 걸로 교체하면 세 채널이 한 브랜드로 보임

## 처음 2주 올릴 것 (촬영 없이 가능한 것부터)
인스타 릴스 4개(launch-event 폴더)는 틱톡·유튜브 쇼츠에 그대로 올라갑니다. 같은 영상을 세 곳에 올리되, 캡션 첫 줄만 플랫폼에 맞게 바꿉니다.
1. 경품 공개 릴스 → 틱톡·쇼츠 (오늘)
2. 앱 둘러보기 릴스 → 틱톡·쇼츠 (10/13)
3. D-3 → 10/22, D-1 → 10/24
4. 유튜브 긴 영상 1편(3~5분): "스키장 개장 전 꼭 할 것 5가지" — 앱 화면 녹화 + 자막 + 무료 배경음악(유튜브 오디오 라이브러리). 썸네일 틀 그대로 사용
5. 쇼츠 시리즈 "오늘의 스키장 웹캠" — 개장 후 매일 아침 앱 웹캠 화면 15초 캡처 + 날씨 한 줄. 촬영 없이 매일 올릴 수 있는 가장 쉬운 콘텐츠

## 업로드 설정
- 쇼츠/틱톡: 9:16, 60초 이내, 제목 앞에 핵심 단어("곤지암 렌탈 가격"), 해시태그 3~5개(#스키 #스노보드 #스키장 #스노우판 + 리조트명)
- 유튜브 긴 영상: 제목 40자 이내, 설명 첫 두 줄에 앱 링크, 챕터 타임스탬프
- 올리는 시간: 평일 저녁 7~9시, 주말 오전 10시
